## Authorization & security

Covered in `tests/test_phase7_security.py` (+ earlier tenant/auth suites):

- Cross-tenant / cross-identity denial
- Unauthorized persistent overwrite (409)
- Forged evidence → validation fail
- Prompt injection in mission logs → no auto-publish

## Reliability

Covered in `tests/test_phase7_reliability.py`:

- LLM timeout / malformed → soft-fail, no publish
- Duplicate learning job idempotent
- Concurrent APPROVE → one success, one 409
- MinIO unavailable does not block core path; bucket upload/download when MinIO up
- Postgres reconnect smoke
- Failed validation leaves no new approved version / no duplicate active knowledge
- Worker mid-job kill: **BLOCKED** in unit suite (see above)

8. Cleanup policy for long-lived synthetic residue in shared environments (dev DB currently retains Phase 2–7 test artifacts by design)
